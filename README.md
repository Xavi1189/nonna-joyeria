# NONNA Joyas & Accesorios

App de catálogo, ventas, recepciones e inventario para NONNA Joyas & Accesorios.

- `index.html` — la aplicación completa (una sola página, sin proceso de build).
- Conectada a Supabase (base de datos, autenticación y permisos).

## Desarrollo local

No requiere instalación: abre `index.html` en un navegador, o usa cualquier
servidor estático (por ejemplo `npx serve .`).

## Despliegue

Este proyecto se publica en Vercel como sitio estático — no necesita configuración
de build. Cada `git push` a la rama principal despliega una nueva versión.
